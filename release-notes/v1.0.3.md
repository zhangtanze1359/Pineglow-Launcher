## 修复

- 修复 Java 自动查找耗时过长时，本地诊断迟迟无法返回、AI 诊断难以及时进入可取消状态的问题。
- Java 版本检测现在同时读取标准输出和错误输出，对超时或已取消的检测回收子进程，避免异常 Java 程序持续占用后台资源。
- 自动查找优先使用 JAVA_HOME、PATH 与常见安装位置；兜底搜索限制在安装根目录下四层、最多 4096 个子目录，并跳过目录联接。特殊深层安装位置可在设置中手动指定。
- 诊断优先验证实例或全局设置中配置的 Java，补充版本信息最多等待约 1 秒；未取得版本时保留信息缺失状态，本地规则和 Mod 分析仍正常返回。
- 修复 Linux 构建测试的 PowerShell 命令选择，并消除 Java 测试夹具的跨平台路径冲突。

## 更新方式

下载本页的 `Pineglow-Launcher-win-x64-single-file.exe`，放入可写目录后运行；已有用户也可通过启动器检查更新。启动器的实例、账户和游戏文件继续保存在各自原有的数据目录。
