## 主要修复

本版是维护版，只包含用户反馈的三项启动与下载页问题，以及游戏秒退的显式提示。

- **启动失败不再一点反馈都没有**：点“开始游戏”后会先做启动前检查，按钮立刻进入忙碌态并提示
  “正在检查游戏和 Java 环境…”。检查不返回时不再静默卡住，而是弹出“启动前检查未完成”，
  给出重试入口；检查不通过时列出具体原因，并把可执行的修复入口（去安装版本、去设置 Java 等）
  直接放在弹窗里，不会再把用户丢回原页面自己找。
- **缺 Java 与失效 Java 路径会被预检拦下并可恢复**：v1.0.8 已能自动下载缺失的 Java；本版补的是失效、不兼容旧 Java 路径的预检拦截、安装后版本校验与失败重试。启动前发现没有匹配的 Java 时，会从 Adoptium 官方源自动下载安装（Temurin 21），装完校验版本后继续启动；安装失败会给出结构化错误并可重试，不会再出现“预检说没问题、一启动就失败”。
- **下载页先出来，两个列表各自加载**：版本列表或任务列表任何一个请求挂起时，页面骨架
  不再跟着一起卡死。骨架恒定几毫秒先显示，任务列表与版本列表独立加载、互不遮挡；
  慢源只拖慢对应那一侧；离线时仍显示本地已装版本，并保留重试入口；快速切页不会被
  旧请求覆盖。
- **镜像清单异常会正确回退**：镜像返回结构错误、整表都是坏记录时回退官方源；
  混入 null、字符串、数字等非对象条目时保留同数组里的有效版本和原顺序，不误判为坏源；
  合法的空清单仍显示空态。
- **切换下载源不再误报失败**：选择 BMCLAPI 后提示成功、当前来源与配置读回一致；
  首次保存失败可以直接重试；迟到的成功或失败响应不会覆盖后来打开的其他弹窗。
- **游戏秒退会明确提示**：游戏进程在启动后 15 秒内退出、或退出码非 0 时，界面会弹出提示，
  写明退出码与运行时长，并指向设置里的本地诊断查看日志；同一次退出只提示一次，
  连续多次退出会逐条排队显示，重启启动器不会补报历史退出；正常长会话退出保持静默。

## 已知问题

- **只支持 Windows x64**，本版为 win-x64 单文件。
- **从 v1.0.4 起的自动更新曾不能保证成功**：旧版本自带的替换脚本有缺陷，是那批版本自己生成的，
  任何后续版本都无法补救；从 v1.0.5 之后的新版本开始才恢复正常。同 v1.0.8 说明。
- **v1.0.4 / 1.0.5 / 1.0.6 使用过的 CurseForge Key** 已在公开仓库历史中出现，平台侧无吊销入口，
  属已接受风险；v1.0.7 起已换用新 Key，v1.0.4～v1.0.6 的用户建议尽早升级。
- **已知降级：启动响应丢失时该次退出不提示**。若本地通信异常导致启动请求的响应没回来、但游戏进程
  实际已拉起，这一局退出时界面不会弹退出提示（只写日志）。已登记为 v1.0.10 改进项。
- 启动器配置文件损坏时（如手动改坏 config.json），界面会回退到默认实例，且该默认实例
  可能在不同接口间不一致；遇到这种情况请删除或改回 config.json。已登记为后续改进项。

## 更新方式

**从 v1.0.5～v1.0.8 升级**：直接用启动器内的“检查更新”下载即可，配置与存档不受影响。

**从 v1.0.4 或更早版本升级**：下载页取 `Pineglow-Launcher-win-x64-single-file.exe`，覆盖到原目录即可（那批版本自带的替换脚本有缺陷，无法在线自更新）。

本版为 Windows x64 单文件版，GPL-3.0 开源协议，仓库页 `LICENSE`，对应源码见同标签的 Source code。
