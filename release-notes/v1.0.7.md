## 安全更新

本版的主要目的是**更换内置的 CurseForge API Key**，不是新增功能。

- **内置 Key 已更换**：CurseForge 的 API Key 使用多年，且曾以明文形式出现在公开仓库的
  历史提交中。本版起改用**构建期注入**——源码仓库里不再包含 Key，只有打包好的程序里才有。
- **对用户无影响**：CurseForge 的模组浏览与下载照常可用，不需要填写任何 Key。

> **如果你是从 v1.0.6 或更早版本升级**：直接覆盖即可，设置不会丢。
> 旧版本内置的是另一把 Key，截至本版发布时**在 CurseForge 侧仍可正常调用**，
> 但它已被公开披露，存在被他人使用的风险。**建议尽早升级到本版。**

## 其他

- 新增一个诊断参数 `--print-curseforge-key-status`，用于发布流程自检。
  它只输出 `curseforge-key=present` 或 `curseforge-key=absent`，**不启动界面，也不会输出 Key 本身**。
  普通用户无需使用。

## 已知限制

- **仅支持 Windows x64**。本版本为 win-x64 单文件。
- **从 v1.0.4 的在线自动升级不能保证成功**（沿用此前的说明）：v1.0.4 自带的替换脚本有缺陷，
  那段脚本是 v1.0.4 自己生成的，任何后续版本都修不了它。从 v1.0.5 起可正常在线升级。
- **更新源的第一顺位（Gitee）此前长期返回 404**，本版发布前后已修复，
  现在检查更新会直接从 Gitee 取到清单，失败时才回退到 GitHub。

## 更新方式

**从 v1.0.5 或 v1.0.6 升级**：直接使用启动器内的「检查更新」即可，不需要手动替换。

**从 v1.0.4 或更早升级**：请先手动覆盖一次可执行文件到 **v1.0.5 或更高**（或直接覆盖到本版本）。

下载本页的 `Pineglow-Launcher-win-x64-single-file.exe`，放入可写目录后运行。

本版本为 Windows x64 单文件版本。GPL-3.0 许可证见本页 `LICENSE`，对应源码见本次标签的 Source code 附件。
