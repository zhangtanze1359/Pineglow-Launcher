## 新增

- 启动后自动检查新版本，运行期间每 10 分钟检查一次，恢复前台时补查。
- 发现新版后展示版本介绍，并保留页面更新提醒，方便稍后查看。

- 更新启动器图标与标题栏视觉。

## 修复

- 修复主更新源仍为旧版时，无法发现备用源新版本的问题。
- 更新介绍优先读取对应 GitHub Release 的说明；网络不可用时使用更新清单中的说明。
- 修复重新打开启动器后，保存的实例与账户选择没有正确显示的问题；现在首页会保留已保存的实例，开始游戏也向该实例启动。
- 修复设置页面未正确读取已保存的代理、下载源和快捷行为配置的问题；不修改直接保存代理时会保留原地址、端口与启用状态，代理密码继续保持隐藏。
- 修复下载源选择弹窗异常，补充加载提示、失败重试、当前选中标记以及重复保存保护。
- 修复 AI 诊断开关保存后状态不同步、保存失败时未恢复原值的问题；保存期间开关会暂时禁用。
- 修复存档与服务器列表读取失败时被显示为空列表的问题，现在会显示明确错误与重试入口，并区分"确实没有数据"。

## 更新方式

在提示中选择“前往更新”，下载完成后点击“立即重启更新”。本版本保留手动下载和重启确认。
