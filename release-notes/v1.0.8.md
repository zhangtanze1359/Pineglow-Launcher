## 问题修复

本版集中处理了一批用户反馈与数据安全问题。

- **大体积整合包现在能导入了**：过去超过约 24 MB 的整合包在导入时必然失败，
  界面显示「fileBase64 不能为空」——这是因为整包内容被转码后塞进一个网络请求，
  超过了请求体大小上限。本版改为**分块上传**：文件被切成小块逐个发送，
  服务端边收边落盘，导入进度也会显示百分比。小体积整合包仍走原来的单请求路径。
- **Java 缺失时自动下载安装**：过去启动时找不到合适版本的 Java 会直接报错，
  提示文案甚至让用户「去导入一个整合包」来装 Java。本版把整合包导入链路里
  早已存在的自动安装能力（Adoptium/Temurin 官方源）接到了正常启动路径——
  现在缺 Java 时会自动下载并继续启动；下载失败时给出真实原因。
- **「打开日志目录」按钮修复**：该按钮调用的接口路径与后端注册的不一致，
  点击必然失败（404）。本版修正，并新增了防止「前端调用了不存在的接口」的
  自动化守卫——这类缺口以后会在 CI 里直接暴露，而不是等用户点按钮时发现。
- **存档删除的数据安全加固**：修复了一个可能导致**存档副本丢失**的边角情况——
  跨盘符删除存档时，若「复制到恢复区成功、删除原目录半途失败」，程序此前会把
  恢复区里那份**已校验完整的副本也删掉**，造成两边都不完整。现在这种情况下
  副本一律保留，界面会明确提示去恢复区找回。
- **退出时自动备份失败不再静默关窗**：开启了「游戏退出后自动备份 + 自动关闭启动器」
  的用户，此前在备份失败或超时（超过 20 秒）时窗口照样关闭——用户以为已备份，
  实际可能没有。本版起：备份失败、部分失败或超时时**保留窗口**并说明原因，
  只有备份成功才按设置自动关闭。

## 界面焕新

- **全新「森系星夜」二次元视觉风格**：整套界面重绘——深海夜松暗色基底、
  荧光薄荷/樱红霓虹/星芒金三色点缀、首页看板娘插画与漫画速线、
  侧栏贴纸头像、皮肤工坊 3D 星夜舞台、新闻 Zine 网点封面。
  全部 78 个设计 token 走语义变量，支持 `prefers-reduced-motion`。
  功能与数据布局不变，纯视觉层更新。

## 新增

- **反馈入口**：设置页新增「反馈」区。反馈会保存为本地文件（自动附上版本、
  系统信息与最近日志），把生成的文件发给开发者即可——
  解决「出了问题没地方说」。

## 已知限制

- **仅支持 Windows x64**。本版本为 win-x64 单文件。
- **从 v1.0.4 的在线自动升级不能保证成功**（沿用此前的说明）：v1.0.4 自带的
  替换脚本有缺陷，那段脚本是 v1.0.4 自己生成的，任何后续版本都修不了它。
  从 v1.0.5 起可正常在线升级。
- v1.0.4/1.0.5/1.0.6 内置的 CurseForge Key 曾以明文出现在公开仓库历史中；
  该 Key 截至本版发布仍在 CurseForge 侧有效（平台不提供删除入口）。
  **本版已换用新 Key**，建议尽早升级。

## 更新方式

**从 v1.0.5 / v1.0.6 / v1.0.7 升级**：直接使用启动器内的「检查更新」即可。

**从 v1.0.4 或更早升级**：请先手动覆盖一次可执行文件到 v1.0.5 或更高
（或直接覆盖到本版本）。

下载本页的 `Pineglow-Launcher-win-x64-single-file.exe`，放入可写目录后运行。
