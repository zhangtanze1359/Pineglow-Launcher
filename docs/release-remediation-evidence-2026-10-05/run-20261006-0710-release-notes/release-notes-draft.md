## 2. 本版做了什么（用户可见）

**发布/运行可靠性（本轮整改 R01–R05）**

- **单文件 EXE 自足**：只把这一个 `.exe` 复制到全新目录（含中文/空格路径）即可启动，
  不再要求旁边有 `UI/` 目录或 Skia 等原生库（R01）。
- **界面资源闭包**：界面 HTML/CSS/JS 的本地引用逐项核对过，缺文件不会静默降级（R02）。
- **更新源有备用**：默认源（Gitee 固定 `update.json`）不可用时，自动回退到 GitHub Release 的
  `manifest.json`（R03）；下载后强制校验 SHA256，篡改会被拒绝。

  变成发版必经项，失败即不发布（R05）。

## 3. 已知限制

1. **仅支持 Windows x64**（`win-x64`）；无 arm64/x86 构建。
2. **需要 WebView2 Runtime**：Win11 与较新的 Win10 一般已内置；缺失时界面无法显示，
   请安装 Evergreen Runtime 后重试。
3. **不是所有外部服务都可用**：新闻、AI 诊断、皮肤等依赖第三方站点，其可用性不受本版控制。
4. **升级横幅可能残留**：如果你之前用旧版做过一次失败的自动替换，设置页可能出现**来自旧版本**的
   "上次替换失败"提示（旧版留下的 `apply-state.json` 会被原样继承，见 `run-20261006-0640-stale-apply-state/`）；
   它只影响显示，不影响本版功能。
5. 【待产品决定是否写入】部分版本列表接口在超时时会返回"暂无可下载版本"
   （`/api/versions/remote` 30 秒超时后 HTTP 500，属既有行为）。
6. **🔴 全新安装后"默认游戏"实例可能无法启动**（默认实例的 id 不稳定 ⇒ 报"实例不存在"；**先做一次会保存的操作**——例如添加账号或改任意设置——即可恢复；
   若本版未修，建议在首次启动引导里提示"先添加账号"）：`run-20261006-2100-default-instance-id/`。
7. **🔴 Forge / NeoForge 实例当前无法安装**（安装器 URL 多了一段 ⇒ 下载必然 404，见 `run-20261006-1900-forge-url-probe/`）；
   **含 Fabric / Forge / NeoForge 加载器的实例当前无法启动**：启动约 10 秒后崩在
   `UnsatisfiedLinkError: Failed to locate library: lwjgl.dll`（命令行缺 `-Djava.library.path`，
   根因与修法见 `run-20261006-1230-fabric-launch/`、`run-20261006-1300-fabric-fix-sim/`）。
   **Quilt 与 Vanilla 不受影响**（Quilt 已实测：49 mod 的包正常进入渲染管线）。
   ⚠️ 若本次发布前**未修**这一条，本节必须保留，且**不要**把"整合包导入"当作卖点
   （"装得上"不等于"起得来"）。
7. **需要自备 Java**：程序内**没有**内置 JRE；缺 Java 时"启动"会被正确拦截并提示去设置里指定路径。
   可自动下载的只有 **Java 17 / 21 / 25**（整合包导入时会自动装需要的那个版本）。
8. **代理设置需"保存一次"才生效**：在设置里保存代理后**当次会话**有效，**重启后**启动器自身的网络请求会走直连
   （已实测，见 `run-20261006-1430-forge-404-trace/proxy-apply-test.ps1`）。

## 4. 迁移说明（**旧版用户必读，两条都不能省**）

### 4.1 从 ≤1.0.0 升级时，可能停在"正在应用更新"

> 从 ≤1.0.0 升级时，如果你是通过脚本/父进程（stdin 被重定向）启动的启动器，
> 更新可能长时间停在"正在应用更新"。请手动下载一次新版；新版已修复该等待写法。

原因：旧版的替换脚本用 `timeout /t 1 /nobreak`，等待循环没有上界；从资源管理器正常双击启动的用户不受影响。

### 4.2 升级后请删除启动器旁的 `UI/` 目录

从**目录式**安装（启动器旁边有 `UI/` 目录）升级后，**请删除那个 `UI/` 目录**：
本版界面已内嵌，而解析顺序里"EXE 旁的 `UI/`"**优先于**内嵌包，不删就会继续用旧界面。

- 诊断：启动日志 `[LocalApi] 监听 …, ui=<根路径>`，`ui=` 指向旧目录即中招。
- 旁边残留的原生 DLL **无害**，不需要清理。

### 4.3 配置、凭据与实例不会丢

配置目录（`%APPDATA%\MCMiniLauncher`，便携版为 `<EXE>\data`）、凭据前缀与实例目录
（`<游戏目录>\instances\<名称>`）与 v1.0.0 **一致**，字段是加法式的、旧配置能直接加载；
安装过程**不写注册表**。
