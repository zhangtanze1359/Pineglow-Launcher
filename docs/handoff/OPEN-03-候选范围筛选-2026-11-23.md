# OPEN-03 候选范围筛选 · v1.0.6

**基线**：`v1.0.5`（tag `e1b77f1`，2026-11-19）
**候选版本**：`1.0.6`
**筛选方法**：不按 `git log v1.0.5..HEAD` 直接列，而是**按产品内容判断**——因为 main 是双线结构，部分提交虽是 v1.0.5 的非祖先，其内容却可能早已随发布线交付。

## 判定口径

对每个候选，问两个问题：

1. **v1.0.5 用户手里有没有这个能力？**（用 `git grep <关键词> v1.0.5` 硬查，不凭印象）
2. **当前 HEAD 有的，是不是 v1.0.5 没有的？**（`git grep <关键词> HEAD`）

两侧都有 → 不算新变化；v1.0.5 缺失 / HEAD 新增 → 算新变化。
