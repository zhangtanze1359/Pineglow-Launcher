## 三、完成时的报告格式

```
任务：<ID>
状态：完成 / BLOCKED（附原因）
改动文件：<列表>
自测：<命令> → exit <code>
证据：<证据文件路径>
未做/未验：<明确列出，不留空>
需用户定夺：<有就写，没有写"无">
```

## 四、如果卡住

- 依赖没成立 → 停下来写 `BLOCKED`，不要"边做边等"
- 发现别处的缺陷 → 记进证据，不要顺手修（那不是你的边界）
- 发现规范互相矛盾 → 写进「需用户定夺」，不要自己裁决
