## 二、渠道（**均需授权后才能使用**）

| 渠道 | 适用类别 | 授权要点 |
|---|---|---|
| 熟人/社区私信 | 任意 | 需你确认**身份披露方式**（是否用真实项目名、谁的名义） |
| 整合包作者的公开联系方式 | `B-PACK` | 需你确认**联系模板**与是否提及商业意图 |
| 社区群/论坛招募帖 | 新手 | 需你确认**发帖平台与文案**；不得承诺未实现的功能 |
| 已有用户（若你手上有） | 任意 | **需你明确同意**并说明如何避免打扰 |

**禁止**：未经授权在公开渠道以项目名义招募；不得把"参与研究"包装成"优先体验新版本"。

## 三、招募偏差记录（必须逐条记录，不能只写成功的人）

| 字段 | 说明 |
|---|---|
| 邀请人数 | 分母 |
| 同意人数 / 拒绝人数 / 无回应 | 分别记 |
| 拒绝原因（原话） | 例如"没时间""不装第三方启动器""不信任" |

## 五、受访者须知（招募时逐条说明）

1. 这是**研究**，不是内测福利；不承诺任何功能上线。
2. 你可以随时退出，已收集内容可要求删除。
3. 默认**不录音**、不截屏、不自动上传。
4. 只在你逐次同意时才查看日志，且**先给你看脱敏后的内容**。
5. 你的身份不会出现在研究记录里（只用匿名编号）。
