---

## 一、匿名编号规则

格式：`<类别代码>-<两位序号>`

| 类别代码 | 含义 |
|---|---|
| `A-HMCL` | HMCL 用户 |
| `A-PCL` | PCL 用户 |
| `A-PRISM` | Prism / MultiMC 用户 |
| `B-PACK` | 整合包维护者 |
| `C-NEW` | 新手（≤6 个月） |

示例：`A-HMCL-01`、`B-PACK-03`、`C-NEW-02`

**规则**
1. 序号按**同意参与的先后**分配，不按重要性；
2. 同一人跨阶段（访谈 → 任务 → 跟进）**沿用同一编号**；
3. **编号↔身份对照表**单独存放，**不写入**任何研究记录、不进 MR22 交付物；
4. 记录里**不得**出现：真实姓名、QQ/微信/邮箱、IP、机器名、真实游戏目录路径、账号名；
5. 受访者原话可引用，但引用前检查是否含上述信息（含则删去该片段并标注 `[已删去身份信息]`）。

## 六、数据处置与保留

| 项 | 默认 |
|---|---|
| 采集方式 | 手工/本地；**不接远程遥测** |
| 存放 | 本地目录，文件名仅含匿名编号 |
| 对照表 | 单独存放，不进交付物 |
| 保留期 | 建议 **90 天**（需你最终确认） |
| 删除 | 到期即删；受访者可随时要求提前删除 |
| 外发 | 逐次同意并留痕；默认不外发 |
