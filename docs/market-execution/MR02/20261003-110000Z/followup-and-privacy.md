# MR02 · 7/14 天跟进问卷、放弃原因分类与最小隐私说明

> 本文件是**空模板**。没有任何已发放或已回收的问卷。

---

## 一、7 天跟进问卷（≤5 分钟，6 题）

1. 这一周你有没有再用这个启动器？用了几次？
2. 这周有没有遇到**卡住**的情况？具体是什么、你当时怎么做的？
3. 有没有哪一步你觉得比上次更顺？（如果是，具体哪一步）
4. 有没有**放弃**过某个操作？是什么、为什么放弃？
5. 你有没有再去看/导出过诊断记录？（有/没有 + 为什么）
6. 你希望下周优先修掉哪一件事？（一句话）

**记录字段**：匿名编号、填写日期、是否愿意继续参与 14 天跟进。

---

## 二、14 天跟进问卷（≤10 分钟，8 题）

1. 这两周用了几次？主要用来做什么？
2. 有没有出现过**数据相关**的担心（怕删错、怕存档没了）？
3. 有没有发生过误删/覆盖？当时怎么处理的？
4. 更新过版本吗？更新过程顺利吗？有没有回退过？
5. 有没有把日志或诊断记录发给别人？发给谁、怎么发的？
6. 有没有遇到"提示看不懂"的情况？原话是什么？
7. 你现在还会用别的启动器吗？什么时候会用它们？
8. 如果只能保留一个功能，你会保留哪个？为什么？

## 三、放弃原因分类（taxonomy，**先冻结再归类**）

> 目的：让"放弃"可比较，而不是每人一句主观描述。每一条放弃记录必须落到下列**唯一**一个主类
> （可另附子类与原文）。

| 代码 | 主类 | 判据（出现下列情形之一即归此类） |
|---|---|---|
| `D1-下载` | 下载/网络相关 | 下载慢、失败、超时、镜像不可用、代理问题 |
| `D2-依赖` | 缺前置/版本不匹配 | 提示缺前置 Mod、版本区间冲突、加载器不匹配 |
| `D3-理解` | 看不懂提示/不知道下一步 | 不知道点了会发生什么、不知道去哪找入口 |
| `D4-等待` | 等待过久/无进度反馈 | 长时间无变化、不知道是否还在跑 |
| `D5-信任` | 不信任自动化 | 怕自动禁用/自动替换/自动删除；怕外发数据 |
| `D6-环境` | 环境/权限 | Java 路径、目录不可写、端口占用、WebView2 缺失 |
| `D7-产品缺陷` | 明确的实现问题 | 崩溃、报错、界面卡死、状态与实际不符（**必须附证据**） |
| `D8-其它` | 其它 | 必须写清楚，且**不得**在后续统计里悄悄并入其它类 |

**统计口径**：每类出现次数 + 原始分母（实际参与人数）；`D7` 单独列出并**直接开修复包**，不计入"用户体验"结论。

## 四、最小隐私说明（给受访者看，一页内）

> 下面是**建议文本**，发布前需你确认（是否用真实项目名、存放位置、保留期）。

1. **我们收集什么**：你对操作的**口头描述**、任务耗时、是否成功、以及你**主动**提供的原话。
2. **我们默认不收集**：不录音、不截屏、不自动上传；**不接远程遥测**；不读取你的账号、令牌、存档内容。
3. **日志/诊断记录**：只有在**你逐次同意**的情况下才会被查看；查看前你会先看到**脱敏后的内容**；
   你可以要求删除任何一条。**默认不外发**给任何外部服务。
4. **匿名**：你只会被记录为 `A-HMCL-01` 这类编号；编号与身份对照表**不写入研究记录**。
5. **保留期**：原始记录建议保留 **90 天**，到期删除（保留期需你最终确定）。
6. **随时退出**：任何阶段都可以停止，已收集的内容可要求删除。
7. **不做的事**：不把你的数据用于训练、不公开你的原话原文、不据此对你做任何评价。

## 五、数据处置（默认手工/本地）

| 环节 | 默认做法 |
|---|---|
| 采集 | 纸笔或**本地**表格；不联网 |
| 存放 | 本地目录，文件名只用匿名编号 |
| 备份 | 不上云；如需备份，用你控制的介质 |
| 外发 | **不默认外发**；每条外发都要逐次同意并留痕 |
| 删除 | 保留期到期即删；受访者可随时要求提前删除 |
| 对照表 | 编号↔身份对照表与研究记录**分开存放**，且不进 MR22 交付物 |
