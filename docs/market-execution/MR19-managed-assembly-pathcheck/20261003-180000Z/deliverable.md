# MR19 补测之四 · **托管程序集是否也受路径影响**（MR19 头条结论的跨路径检验）

- **run-id**：`20261003-180000Z`
- **性质**：**对里程碑头条结论的跨路径检验** —— 比"机制好奇心"重要得多
- **依据**：`MR19-reproducible-build-rid/20261003-070000Z/deliverable.md` §2.3：
  "`dotnet build -c Release` → SHA `52C17031…`；`dotnet build -c Release --no-incremental` → SHA `52C17031…`；逐字节一致 = True"
  —— **这两次构建都在同一路径**，因此该结论**只证明了"同路径"**
- **最终状态**：**证据就绪；结果为否定性** —— 托管程序集**同样只在同路径下可复现**，MR19 的头条结论必须收窄

---

## 一、结论（三条）

### 1. **托管程序集（DLL）也是路径相关的**

三个路径**长度完全相同**（98 字符），每次都清 `bin/obj` 独立构建：

| 路径 | 盘 | exe 大小 | **DLL SHA256** |
|---|---|---|---|
| `…\pineglow-drivecheck-<guid>\pgA` | C: | 3,590,144 | `E79EA7421221804E3FB7BB6ECB9512F8F2C5D50742EE789AF78D6515A6EA121A` |
| `…\pineglow-drivecheck-<guid>\pgB` | C: | 3,590,144 | `4F369572687BEE5D872F3BEFCF1081B111B4D2DA850EE4F78AAFB9DBE968D428` |
| `D:\ddd…d`（95 个 d） | **D:** | 3,590,144 | `5F4D75ACC87CD1847A4D6CD265ECB2FD892CEB3750DE01E9232FC78BBA8913D5` |

**A ≠ B**（同盘、同长度、只差一个字符）→ **托管程序集嵌入了路径内容**。
**A ≠ C**（同长度、换盘）→ 跨盘也不同。

> **因此 MR19 的头条结论"托管程序集逐字节可复现"必须加限定：只在同一路径下成立。**

### 2. 对照实验排除了"时间"这一混淆（关键）

DLL 差异会不会只是因为三次构建**相隔约一分钟**？**不是**：

| 实验 | 结果 |
|---|---|
| 在**同一路径 A** 上、相隔约 **2 分钟**再构建一次 | DLL = `E79EA742…`（**与 A 完全相同**） |
| 同上，单文件 exe | = `9D23610F…`（**与 A 完全相同**） |

→ **时间不是因素**；A≠B≠C 只能归因于**路径**。这条对照是本报告结论成立的前提。

### 3. "`0x1AC` 是盘符效应"的猜测**不被支持**

本轮的**跨盘、同长度**对比（A 在 C: vs C 在 D:）：

| 对比 | 首个差异 | 不同字节 |
|---|---|---|
| A vs B（同盘、内容不同） | `0x9AD088` | 85 / 89,490,941（0.0001%） |
| **A vs C（跨盘、同长度）** | **`0x9AD088`** | 176 / 89,490,941（0.0002%） |

**跨盘对比的首个差异也在 `0x9AD088`，不在 `0x1AC`。** 所以上一轮"`0x1AC` 可能来自盘符"的候选
**本轮没有得到支持**；`0x1AC` 至今**只在第 27 轮那组"D: 盘就地构建 vs C: 盘临时目录"**里出现过一次，
**未被复现，原因仍未知**。

## 四、复跑方法

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\measure-singlefile-drivecheck.ps1
```

设计：建**一次**快照 → **复制**到三个等长路径（C:98 / C:98 / D:98）→ 各清 `bin/obj` 发布一次
→ 记录 **DLL / PDB / exe** 三者 → 判读 → 清理 D: 盘临时树（带重试与路径核对）。

**本轮自找并修掉的两个问题**（失败日志都保留）：
1. **移动快照被拒**：`dotnet build-server shutdown` 后 `Move-Item` 仍被拒 11 次
   （MSBuild 常驻节点持有项目目录）。**改为复制三份**（构建前每份仅 5.3 MB）+ 发布加 `/nodeReuse:false`。
2. **`Copy-Item -LiteralPath` 不展开通配符**：导致"复制到 …（0.0 MB）"、项目不存在。
   改用 `-Path`。
