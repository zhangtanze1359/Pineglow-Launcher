## 但**它的价值比缺陷 1 的 UI 入口低**（这是我的判断，说明理由）

**因为 P-JAVAAUTO 已经让"没 Java 也能跑"了**（第 87 轮端到端验证过：无 Java → 自动下载 46.7 MB → 启动成功）。
也就是说：

| 场景 | 现在能不能做到 |
| --- | --- |
| 没 Java，想玩游戏 | **能** —— 点启动就会自动装（P-JAVAAUTO） |
| 没 Java，想**先装好**、或**看着它装** | 不能（没有手动入口） |
| 装了多个 Java，想选一个 | **能**（设置页可以切换） |

**所以 ③ 缺的是一个"便利/可见性"入口，不是"能力"。**
**缺陷 1 当时缺的是能力本身**（完全没法给已有实例装加载器）—— 所以那一条值得做，这一条优先级低。
