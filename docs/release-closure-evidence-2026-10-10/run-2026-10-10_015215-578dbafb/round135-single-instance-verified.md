## 但有一处**我自己的实现瑕疵**：B 的退出码仍是崩溃码

```
B exit code = -532462766        ← 0xE0434352，.NET 未处理异常
```

**它退出了，但不是干净退出** —— 说明 `Shutdown()` 那条路上**抛了异常**。

**最可能的原因**：我在 `OnFrameworkInitializationCompleted()` **还没返回**的时候就调了
`classicDesktopStyleApplicationLifetime.Shutdown()` —— 此时生命周期**尚未完全启动**，
`Shutdown()` 很可能因此抛错。

**可能的修法**（下一轮可试，都很小）：
- 记完日志后 `Environment.Exit(0)`（最直接，不走 Avalonia 的关闭流程）；
- 或者设一个标志、`return` 让框架先完成初始化，再在别处退出。

**我倾向 `Environment.Exit(0)`** —— 这个进程本来就不该继续，**没必要走完整的关闭流程**。
