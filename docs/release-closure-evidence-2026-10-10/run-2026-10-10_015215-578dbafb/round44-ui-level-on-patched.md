## 结论（三条，分开说）

1. **补丁没有造成界面回归。** 补丁版与出厂版渲染出**完全一样**的读数（188 元素 / 700 字符正文 /
   0 异常 / 0 console 错误）。P-JAVALABEL 改了文案，但界面照样正常渲染。
2. **`httpErrors=5` 与 `hasAccountText=false` 是夹具/环境的属性，不是产品缺陷**——出厂构建上**同样存在**。
   最可能的原因是这份夹具的配置里带着一个 Microsoft 账号，而其令牌早已过期 → 账号相关端点返回 401。
   这正是我从早期轮次起就一直标注的「真实凭据不可得」限制。
3. **顺带更正一条旧记录的说法**：记录 18 当时报的是 PASS，那是因为**它用的夹具不同**
   （不含那个过期账号）。探针结果随夹具变化，**不随构建变化**——这一点此前没有写清楚。
