## 1. 为什么先修这一句

第 37 轮把缺陷 13 端到端测通了：无 Java 机器上，设置页显示**「使用内置 JRE（默认）」**，
而 `data/runtimes` 从未被创建、启动被拒（`prelaunch-check ok=False` + `launch HTTP 400`）。

这个缺陷有三部分：① 文案在说谎；② 自动安装没接到启动路径；③ 设置页没有安装入口。
**① 是唯一"纯错误、无争议、改起来几分钟"的部分**，所以先修它。
（②③ 是功能补齐，属产品取舍，仍在报告待办第 19 项里等你决定。）

## 2. 改动

`ui/js/launcher.js:631` 在**用户没配 Java 路径且产品一个 Java 都没检测到**时显示这个标签。
原文案与事实不符，改成实话：

| | 旧 | 新 |
| --- | --- | --- |
| 中文 | `使用内置 JRE（默认）` | **`未检测到 Java，请指定路径`** |
| English | `Use Bundled JRE (Default)` | **`No Java detected - please set a path`** |

改动前已核实：该键**只有一处使用**（`launcher.js:631`），且**没有任何测试断言这个字符串**。
