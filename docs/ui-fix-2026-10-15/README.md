## 证据限制及保留观察

1. 原生以机器已安装的 **.NET 10.0.0** 显式启动；此前默认运行时的HttpListener问题不在本次UI修正范围，不声称已解决。未重跑全部C#后端测试、发布包、干净检出或远程CI。
2. 普通Mod恢复保留后端原有文件名及启用状态。原稿的“默认禁用”描述没有借本次UI修正强制改写后端规则；浏览器夹具的“恢复为禁用”仅验证界面对该返回状态的处理，不能证明真实后端总会默认禁用。
3. 原稿示例的“已安装”、备份数、收藏、结束游戏、暂停、速率等未获真实接口支持的内容不伪造。微软在线登录、上传、真实游戏下载和游戏启动仍未验证。
4. 配对截图用于人工设计对照，自动断言是布局/行为约束，不是像素级相等证明。真实内容与示例数据、文案、已有配置能力会造成已列明的适配。
5. 保存了过程中失败的测试证据：固定4200字符静态扫描边界、旧跳转目标断言、搜索属性顺序、导航读取时机、隐藏账户删除按钮误选及历史恢复记录误选分别定位并修正；`node-directory-final.txt`是错误测试命令的MODULE_NOT_FOUND，不计产品RED或已执行测试。未删除这些记录或将其包装为产品失败。
