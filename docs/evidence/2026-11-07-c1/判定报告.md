### 3.1 预测方法（只读，未执行 cherry-pick）

- 起始状态 = `git ls-tree -r main`（3977 项）；
- 对每个提交的每个改动路径：取 `parent:path`（base）、`commit:path`（theirs）、累积状态（ours）；
  - `ours == base` → 直接取 theirs（干净）；
