# 设计系统（Design System）

> 更新于 2026-10-03。基础样式在 `ui/css/figma.css`，视觉修订在随后加载的 `ui/css/pineglow.css`；**最终激活 token 以 pineglow.css 为准**。采用松林晨光主题，深色基底与柔和绿色强调。
> ⚠️ 旧《UI-UX 设计文档》的"天光蓝 `#7C9CFF`"方案**已被取代**，仅供历史参考（归档中）。

## 二、设计红线（评审必查）

1. **深色默认**：`--base:#10191b` 为基底，`--text:#edf3ef` 为主文字。
2. **对比度**：正文 ≥ 4.5:1；弱注释（`--subtle`）仅限大字号/非关键信息。
3. **动效**：全部 ≤ 600ms，基准 200ms；跟随系统"减少动态效果"。
4. **强调元素**：每屏 ≤ 2 处；强调色面积占比 ≤ 10%。
5. **禁止**硬编码色值；所有颜色走 token。
6. **禁止**用天光蓝（`#7C9CFF`）——已被绿色取代。

## 三、品牌母题（Pineglow = 松光）

- 意象：**松林晨光**。当前以柔和绿色（`#91d5af`）为强调母题。
- 首页封面使用本地可编辑 SVG `ui/assets/pine-forest.svg`，不依赖在线图片。像素松林是品牌装饰，不代表用户存档或新闻内容。
- 渐变仅限品牌 token（启动按钮、Logo、侧栏选中指示条、封面遮罩），卡片/列表/弹窗一律纯色。

## 五、语义色

| Token | 值 | 填充用法 |
|---|---|---|
| Success | `#4ADE80` | 成功/完成/正式版徽标 |
| Warn | `#FBBF24` | 警告/快照版徽标 |
| Danger | `#F87171` | 错误/失败/删除 |
| Info | `#38BDF8` | 进行中/提示 |

> 大面积使用时用 12% 透明度 tint 版 + 30% 同色描边，避免廉价感。

## 六、字体与布局

- 字体：标题使用 `Segoe UI Variable Display`，正文使用 `Segoe UI Variable Text`，中文回退到 `Microsoft YaHei UI`，数据使用 `Cascadia Mono / Consolas`。全部为系统字体，不加载远程字体。Figma 修订稿沿用原稿 Outfit/Geist，新增中文标题使用 Noto Sans SC；以实际 WebView2 截图为运行效果依据。
- 布局：卡片式（`--card`）为主，间距、圆角、阴影统一走设计 token，禁止魔法值。

> 完整视觉规范（页面级规格、动效节奏、阴影、无障碍）见归档《松光启动器UI-UX设计文档.md》的有效章节，但**配色以本文 + pineglow.css 为准**。

## 七、2026-10-03 页面规则与证据

- 首页顺序为封面 → 实例选择与启动 → 资讯，DOM 阅读顺序与视觉顺序一致。
- 宽度 ≤ 760px 时导航收为图标栏，文本仍留在无障碍树中；所有九个页面在 390px 宽度检查了操作控件的横向边界。
- 表单、列表与内容卡片共享色彩与圆角；弹窗保留原有 470px 宽度、整体滚动、粘底操作区和键盘关闭行为。
- `prefers-reduced-motion` 对全界面生效。SVG 封面没有动画。
- Figma 原四稿保留，修订稿位于下方，首页节点 `30:2`，实例 `30:121`，皮肤 `30:252`，设置 `30:335`。这些是基于原设计结构的视觉参考，运行页面的九项导航与数据状态以项目代码为准。
- 验证记录：`docs/evidence/ui-refresh-2026-10-03/`；既有回归 52/52，浏览器观察 29 项，真实 WebView2 四页。
