# Pineglow · 松光启动器 — UI 重构设计契约

> 本文件是重构后的视觉与交互契约，供后续 Harness 集成阶段直接读取。
> 视觉令牌来自当前激活的设计系统 **Raycast**，为本次重构的唯一权威来源。

## 一句话系统

近黑蓝调画布（而非纯黑）承托全部内容，多层级内阴影模拟 macOS 玻璃质感；
Inter 承担全部字重并以 +0.2px 正字距换取暗色可读性；Raycast 红只做标点，不做底噪。

## 六个契约令牌（OKLch 与 sRGB 对照）

| 令牌 | sRGB | OKLch（近似） | 角色 |
|---|---|---|---|
| `--bg` | `#07080a` | `oklch(0.14 0.008 264)` | 页面画布 / 窗口底 — 带蓝调的近黑 |
| `--surface` | `#101111` | `oklch(0.19 0.002 264)` | 卡片、面板、抬升容器 |
| `--fg` | `#f9f9f9` | `oklch(0.98 0 0)` | 主文本、高强调元素 |
| `--muted` | `#9c9c9d` | `oklch(0.70 0 0)` | 次级文本、导航默认色 |
| `--border` | `rgba(255,255,255,.06)` | `oklch(1 0 0 / 0.06)` | 卡片包边 — 几乎不可见但结构必需 |
| `--accent` | `#FF6363` | `oklch(0.72 0.17 22)` | 品牌标点：主行动、启动进度、错误态 |

派生层：`--fg-2 #cecece`（正文）、`--meta #6a6b6c`（占位/元数据）、
`--success hsl(151 59% 59%)`（在线、下载完成）、`--focus-ring hsla(202 100% 67% / .35)`（焦点环用蓝，保护红的稀缺）。

## 字体栈

- 显示 / 正文：`Inter` → `Inter Fallback` → `SF Pro Text` → `-apple-system` → `system-ui` → `Segoe UI` → `Microsoft YaHei UI`
  （Windows 无 Inter 时落到 Segoe UI Variable，仍为本机系统字体，零网络依赖）
- 等宽（版本号、体积、速度、时间戳）：`GeistMono` → `ui-monospace` → `SF Mono` → `Consolas` → `Microsoft YaHei UI`
- OpenType：`calt, kern, liga, ss03` 全局开启；Hero 类标题 `liga 0`
- 字重基线 **500**（暗底不显瘦），标题 600，正文行高 1.6，字距 +0.2px

## 五条观察到的视觉规则

1. **画布不是纯黑。** `#07080a` 的蓝冷底色是这套系统的识别点，禁止使用 `#000`。
2. **包边用半透明白，不用实色描边。** 卡片靠 `rgba(255,255,255,.06)` 与双层环阴影
   （外环 `#1b1c1e` + 内环 `#07080a` inset）分层，而不是 1px 灰线。
3. **阴影成对出现。** 外阴影负责脱离，inset 高光负责受光，inset 暗边负责压底；单层平阴影视为失败。
4. **红的预算只有两次。** 每个视图最多两处出现 `--accent`：一处主行动 + 一处状态/进度。
   蓝色只做交互反馈（焦点、链接、选中），绿色只做成功态。
5. **过渡改透明度与明度，不改色相。** hover 走 opacity/brightness（DS 原生的 `.6` 模式）
   或 L 通道 ±0.06–0.12，绝不在 hover 时把前景色推向背景色。

## 松林资产的处理

`ui/assets/pine-forest.svg`（1000×380，产品自带矢量夜景）保留使用，但重新着色到本契约的令牌：
天空=近黑蓝、落日=`--accent` 低透明度、三层山脊=画布与表面的中间色、松树=近黑。
着色通过 CSS class + `color-mix(in oklch, …)` 完成，文件内不出现新 hex 值。
蒙版方向保持“左实右虚”，保证左侧标题区始终满足对比度。

## 不变量（重构中必须保持）

- 现有 9 个模块与业务语义不变：启动 / 实例 / 世界 / 服务器 / 内容 / 皮肤 / 下载 / 新闻 / 设置。
- 键盘可达、焦点可见、`Esc` 关模态、`aria-live` 播报异步结果、跳转主内容链接保留。
- 尊重 `prefers-reduced-motion`：位移与缩放全部让位于透明度。
- 原型内所有数据为**模拟数据**，任何启动/下载/登录结果都必须显式标注为模拟。
